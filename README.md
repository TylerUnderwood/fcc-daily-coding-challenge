# Free Code Camp Daily Code Challenges

## How to add your own
1. Request access to contribute to this repo.
2. Always use a branch using challenge date and your name.
3. If it is your first time, make a folder in `scripts/DCC` using your Github username.
4. Make your file name just the date of challenge formatted YYYY-MM-DD.
5. Add your nGithub username to the datalist in the `index.html`. Then it will be an option on the challenge form.
6. If the day you are looking to test is already in the `./scripts/DCC/Question` folder, you can select it from the date field.
7. If the question is not there, you can add it yourself, following the pattern in other Question files.
8. When you're ready you can make a pull request to add your answer and we can review or just merge.
