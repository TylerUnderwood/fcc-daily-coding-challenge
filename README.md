# Free Code Camp Daily Code Challenges

## How to add your own
1. Request access to contribute to this repo.
2. Always use a branch using challenge date and your name.
3. If it is your first time, make a folder in `scripts/DCC` using your Github username.
4. Make your file name just the date of challenge formatted YYYY-MM-DD.
5. There are a couple `<scripts>` on the `index.html`, you can change those file paths to match yours.
6. If I have started I will make a `trunk` push to have the daily test set up in the `scripts/DCC/Questions` folder. 
  - If that is there you should be good to go, otherwise feel free to add it yourself following previous setups.
7. When you're ready you can make a pull request to add your answer and we can review or just merge.
